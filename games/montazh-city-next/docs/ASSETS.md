# Ассеты: откуда, под какой лицензией и как пересобрать

Всё, что грузит игра, лежит в `public/assets/` (в сборке это `assets/`). Пути и
статус каждого ассета записаны в [`src/assets/manifest.js`](../src/assets/manifest.js).
Там же перечислено, чего пока нет и чем это временно заменено.

Итого около 41 МБ: персонажи 18.5, реквизит 13, текстуры 11, небо 0.8,
машина 1.8.

## 1. Poly Haven — всё CC0

Лицензия: <https://polyhaven.com/license>. Можно без указания авторства и в
коммерческом проекте. Полный список — [`assets-src/sources.json`](../assets-src/sources.json).

| Что | Ассеты | Для чего |
| --- | --- | --- |
| Небо | `kloofendal_38d_partly_cloudy_puresky` | Видимое небо и освещение (IBL), солнце на 38°, как в пять вечера |
| Текстуры | `asphalt_02`, `concrete_pavers`, `brown_mud_leaves_01`, `sparse_grass`, `yellow_plaster`, `concrete_slab_wall`, `concrete_wall_006`, `red_brick_03`, `dirty_concrete`, `concrete_floor_worn_001`, `green_metal_rust`, `corrugated_iron_02`, `worn_plaster_wall`, `tree_bark_03` | Дороги, тротуарная плитка «кирпичик», дворы, штукатурка конторы, панельки, гаражи, цоколи, бордюры, ворота, кровля |
| Модели | `security_light`, `modular_electricity_poles`, `utility_box_02`, `security_camera_01/02`, `exterior_aircon_unit`, `metal_trash_can`, `wooden_crate_01`, `cardboard_box_01`, `plastic_crate_01`, `plastic_monobloc_chair_01`, `old_tyre`, `ladder_sectioned_01`, `metal_toolbox`, `covered_car`, `concrete_road_barrier`, `water_manhole_cover`, `modular_chainlink_fence`, `shrub_02`, `grass_medium_01/02`, `dandelion_01`, `weed_plant_02`, `celandine_01`, `nettle_plant` | Фонари «кобра», опоры с изоляторами, электрощиток, камеры на фасаде и на опорах, кондиционеры, двор бригады, трава и сорняки |

Пересобрать:

```bash
npm run assets                              # скачать по sources.json (сверяет md5)
node tools/assets/pack-textures.mjs         # текстуры в WebP, небо — в JPG и HDR без солнца
node tools/assets/pack-props.mjs            # модели в GLB с WebP-текстурами, только нужные детали
```

Деревья Poly Haven весят 60–200 МБ (каждый лист у них — отдельная сетка). Поэтому
деревья строятся кодом (`src/engine/babylon/vegetation.js`): ствол и ветви
трубками, крона — карточками с пучками листьев. Кора берёзы и листва рисуются на
холсте при загрузке.

## 2. Персонажи и машина — сгенерированы для этой игры

Все модели сделаны под эту игру в три шага:

1. **Портрет в A-позе** — Krea 2 Large, промпт в духе старой игры. Для Олега это
   кожаный шлем с очками, майка, жёлтый жилет, оранжевые штаны с наколенниками,
   сумка.
2. **3D-модель по портрету** — Hunyuan3D-2.1 через Krea: 40 тыс. треугольников,
   текстура 4096 и карта металличности и шероховатости.
3. **Риг и анимации** — [`tools/assets/rig-character.mjs`](../tools/assets/rig-character.mjs),
   собственный автоматический риггер:
   - модель ставится на ноги: Y вверх, рост в метрах, лицом на +Z;
   - суставы находятся по срезам сетки: промежность, линия плеч, ось руки,
     колени по пропорциям. Их можно поправить в `assets-src/<id>/rig.json`;
   - веса считаются по расстоянию вдоль поверхности, а не по прямой, и
     размываются, как тепло. Позвоночник размечен полосами по высоте;
   - «подставка» под ногами, которую иногда добавляет генератор, срезается;
   - добавляется дальний уровень детализации: те же вершины, но в 4,5 раза
     меньше треугольников;
   - клипы Mixamo переносятся на свой скелет с выравниванием направлений костей.
     Поэтому A-поза модели и T-поза донора не мешают друг другу. Для шага и бега
     считается «родная» скорость, по ней игра подбирает темп, чтобы ноги не
     скользили.

```bash
node tools/assets/rig-character.mjs --cfg assets-src/oleg/rig.json   # то же для любого персонажа
```

**Машина** — «семёрка», сделанная тем же путём (портрет → Hunyuan3D-2.1).
[`tools/assets/build-car.mjs`](../tools/assets/build-car.mjs) подгоняет её под размер
«седана» старой логики и ставит носом на +Z. Он сам находит колёса по пятнам
касания и подбирает радиус шины, а затем вырезает колёса в отдельные узлы, чтобы
они крутились. Там же он строит маску эмали: игра перекрашивает одну модель в семь
цветов старой палитры, не трогая хром, стёкла и резину.

**Доноры анимаций** — `Xbot.glb` и `Soldier.glb` из примеров three.js (MIT). Сами
клипы оттуда из библиотеки Mixamo (Adobe). Mixamo разрешает использовать их в
играх владельцу учётной записи Adobe. Перед релизом те же клипы лучше выгрузить
из Mixamo своей учёткой.

Исходники генератора (GLB по 12–15 МБ) и доноры в git не лежат: они большие и
нужны только для пересборки. Чтобы собрать заново, файлы кладут на старые места:

## 3. Чего пока нет

Список лежит в `PLANNED` в `manifest.js`, у каждой строки есть запасной вариант.

| Нужно | Сейчас вместо этого | Что требуется |
| --- | --- | --- |
| Собака | собрана кодом из трубок (`critters.js`) | модель и четвероногий риг, клипы бега, лая и лёжки |
| Прохожая, охранник, клиент заявки | прохожий `ped_man` | 3 портрета → 3 модели → риг, 5 минут на каждого |
| Фургон, пикап | «семёрка» | 2 модели, тот же `build-car.mjs` |
| Клипы действий: отвёртка, стремянка, замах, падение | процедурные слои поверх шага | клипы Mixamo, риг их примет без правок |

Генерация 3D через Krea упёрлась в тариф: Hunyuan3D 3.1, TRELLIS 2, Meshy 7,
Rodin и Tripo закрыты на текущем плане, а баланс почти израсходован. Бесплатная
квота ZeroGPU на Hugging Face без токена кончилась за день. Доделать список выше
можно так:
- поднять тариф Krea (3D лучшего качества там же);
- или запустить TRELLIS.2 / Hunyuan3D на Hugging Face со своим токеном
  (`HF_TOKEN`), с той же цепочкой после генерации.
