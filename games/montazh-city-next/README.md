# Монтаж-Сити на Babylon.js

Та же игра, что `games/montazh-city-3d/`: смена, заявки, бригада, район и все его
жители. Но кадр рисует Babylon.js, а не самописный WebGL. Олег, бригада, прохожие и
«семёрки» — настоящие 3D-модели со скелетом. Земля, дома и дороги сделаны на
фото-текстурах. Небо и свет взяты с HDR-панорамы.

Логика не переписывалась: это модули старой игры, нарезанные из монолита
автоматически (`src/legacy/`). Поверх них работает новый бэкенд отрисовки
(`src/engine/`).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5178/ — игра, /viewer.html — просмотр моделей
```

Качество: `?q=high` (по умолчанию), `?q=medium`, `?q=low`. Оно же переключается в
настройках игры. На Mac с M4 «высокое» держит около 55–60 кадров в секунду при
2160×1350. Рендер сам уменьшает разрешение, если кадр не успевает.

## Сборки

| Команда | Что получается |
| --- | --- |
| `npm run build` | `dist/`: игра и просмотрщик моделей, код разбит на части |
| `npx vite build --config vite.game.config.js` | `dist-game/`: только игра, весь код одним файлом. Эту сборку выкладываем |
| `npm run build:legacy` | `dist-legacy/legacy.html`: старая игра из модулей, один офлайн-файл, как исходный монолит |

## Как устроено

```
src/
  legacy/            старая игра по модулям — СГЕНЕРИРОВАНО, руками не править
    core/ world/ game/ ui/ audio/ save/   логика и интерфейс
    render/                               старый WebGL-рендер («старый бэкенд»)
    main.js, style.css, dom.html          точка входа, стили и разметка HUD
  engine/
    bridge.js        мост: состояние логики → снимок сущностей для отрисовки
    babylon/         новый бэкенд: небо, земля, дома, реквизит, люди, машины
  assets/manifest.js что игре нужно, где лежит, чего пока нет и чем заменено
  game/runtime.js    запуск: те же шаги кадра, что у старой игры, кадр рисует Babylon
  world/yard.js      двор конторы: деревья и лавка сверх старых данных
tools/
  split-legacy.mjs   нарезка монолита на модули (npm run split)
  legacy-parity.mjs  проверка, что игра из модулей = монолиту (npm run check:legacy)
  fetch-assets.mjs   загрузка ассетов Poly Haven по assets-src/sources.json (npm run assets)
  assets/            подготовка ассетов: риг персонажей, машина, текстуры, реквизит
  snap.mjs           снимок страницы в Chromium, с нажатием клавиш и замером
```

## Монолит и модули

Пока другие сессии правят `games/montazh-city-3d/index.html`, источником правды
остаётся он. Модули не пишутся руками: после правки монолита их пересобирают.

```bash
npm run split            # перенарезать src/legacy/ из монолита
npm run build:legacy     # собрать старую игру из модулей
npm run check:legacy     # сравнить с монолитом: 4 сцены, состояние мира и кадры
```

`check:legacy` открывает обе версии в одном Chromium на виртуальных часах с
фиксированным зерном случайности. Состояние мира (Олег, машины, прохожие, собаки)
должно совпасть точно. Кадр должен совпасть с точностью до шума видеокарты: два
запуска самого монолита тоже расходятся на единицы в младшем разряде цвета.
