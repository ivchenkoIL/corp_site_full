# Монтаж-Сити: Трудная смена

Сатирическая браузерная 2D-игра про **вымышленного** монтажника систем контроля
доступа и видеонаблюдения Олега Левинцова. Один файл, Canvas 2D, Web Audio,
никаких библиотек, серверов, ключей и регистраций.

> Главный герой, организации и события полностью вымышлены, любые совпадения
> случайны. В игре нет реальных людей, фотографий и персональных данных.
> Схемы монтажа условны: это головоломка, а не инструкция по работе с
> настоящими охранными системами.

## Запуск

```bash
# вариант 1 — просто открыть файл
xdg-open games/montazh-city/index.html      # Linux
open games/montazh-city/index.html          # macOS
start games\montazh-city\index.html         # Windows

# вариант 2 — через любой статический сервер (не обязательно)
npx http-server games/montazh-city -p 8080  # затем http://localhost:8080/
```

Требуется актуальный Chrome (проверено в Chromium 141). Игра работает офлайн,
из `file://`, и подстраивается под размер окна. Звук включается после первого
клика или нажатия клавиши — так требует политика браузеров.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D` / стрелки | движение |
| `Shift` | ускорение (тратит выносливость) |
| `Space` | тормоз на велосипеде, уклонение пешком |
| `E` | действие: сесть на велосипед, начать монтаж, говорить, сдать работу |
| `F` | инструмент: отмахнуться сумкой, фонарик, поправить слетевшую цепь |
| `1…8` | выбрать инструмент в сумке |
| `M` | карта района |
| `R` | рабочий телефон (журнал заявок и статистика) |
| `Q` | переключить радиостанцию |
| `C` | вызвать напарника Саню |
| `Esc` | пауза / закрыть окно |
| мышь | мини-игры монтажа и все кнопки интерфейса |

В мини-игре камеры: `A/D` — поворот, `W/S` — наклон, `Z/X` — зум,
`F` — отогнать того, кто раскачивает опору, `E` — подтвердить ракурс.

## Что внутри

* Открытый район «Заводская Слобода» 3200×2400: дворы с панельками, промзона,
  гаражи, магазины, парковка бизнес-центра.
* Ходьба и велосипед с физикой: разгон, торможение, занос, столкновения,
  износ, слетающая цепь, ямы на дорогах.
* Здоровье, выносливость, деньги, репутация, состояние велосипеда, сумка с
  инструментом, смена времени суток и «уровень внимания» района.
* Шесть заявок: две двери СКУД (одна — на время), камера на опоре, поиск
  украденного шуруповёрта, ночная промзона с фонариком и финальный большой
  объект из пяти этапов с обороной кабеля.
* Две мини-игры монтажа: коммутация условной схемы двери и установка камеры
  (высота → крепёж → питание и сеть → ракурс с проверкой охвата зоны).
* Дворовые хулиганы трёх типов, собаки, машины, прохожие, бабушки-свидетели и
  ЧОП «Бдительный сосед», приезжающий на высокий уровень внимания. Прохожие
  отскакивают от несущегося велосипеда и ворчат; сбить прохожего — это минус
  здоровья и заметный плюс к «уровню внимания».
* Магазин инструмента, мастерская с апгрейдами велосипеда, чайная и разливная
  (заходить туда — плохая идея, и игра честно это показывает).
* Радио с тремя процедурными станциями, бегущая строка с пародийной рекламой.
* Автосохранение в `localStorage` каждые 20 секунд и на ключевых событиях.
* После сдачи большого объекта смена не заканчивается: можно остаться в районе
  и брать бесконечные сгенерированные заявки на двери и камеры с растущей
  оплатой (сводка по ним — в журнале на `R`).

## Чек-лист проверки

1. **Запуск.** Открыть `index.html` — появляется меню «Монтаж-Сити».
2. **Движение.** «Новая смена» → пройти обучение: ходьба, `Shift`, посадка на
   велосипед (`E`), поездка, тормоз (`Space`), карта (`M`).
3. **Первая заявка.** Дождаться звонка Тамары → доехать до склада (жёлтый
   маркер и стрелка на экране) → `E` → комплект в сумке.
4. **Мини-игра двери.** Доехать до подъезда → `E` → расставить оборудование
   (мышью или с клавиатуры: `←/→` — прибор, `↑/↓` — место, `E` — поставить;
   ошибка стоит качества), соединить одинаковые метки A/B/C/D, запустить
   проверку, увидеть журнал прохода.
5. **Проверка и оплата.** `E` у объекта — проверка, затем `E` у заказчика —
   деньги и репутация.
6. **Противники.** Подойти к хулигану во дворе: диалог с пятью вариантами,
   среди которых всегда есть мирный. Собаки и машины бьют по здоровью,
   разбитый киоск поднимает «уровень внимания» и вызывает ЧОП.
7. **Сохранение.** `Esc` → «Сохранить», перезагрузить страницу → «Продолжить»:
   деньги, репутация, апгрейды и номер заявки на месте.
8. **Финал.** Шестая заявка «Большой объект»: СКУД, четыре камеры, оборона
   кабеля, сдача заказчику → экран «Смена сдана» со статистикой.
9. **Свободный режим.** На экране «Смена сдана» нажать «Остаться на смене» →
   Тамара присылает сгенерированную заявку, её видно в журнале (`R`) отдельной
   строкой со сводкой.
10. **Поражение.** Здоровье до нуля (машины/собаки) или репутация ниже −25 →
    экран «Смена сорвана» с кнопкой перезапуска.
11. **Если тормозит.** `Esc` → «Настройки» → «Эффекты: экономно» отключает
    закатную цветокоррекцию, виньетку и развёртку — заметно легче на слабых
    машинах. Игра сама один раз подскажет это, если частота кадров низкая.
